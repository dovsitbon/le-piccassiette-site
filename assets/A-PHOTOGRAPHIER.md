# Photos à prendre sur place

Déposez chaque photo sous ce nom exact (JPG, le plus grand possible), puis lancez `npm run media` et poussez sur GitHub : l'aplat illustré est remplacé par la photo partout sur le site.
Lumière du jour, sans flash. Pas de visages de clients reconnaissables.

| Fichier | Où il apparaît | Conseil |
|---|---|---|
| `hero/hero.jpg` | Grande photo d'accueil, image de partage | La plus belle : la salle et sa mosaïque, ou le comptoir. Format paysage. |
| `facade/facade.jpg` | Infos pratiques | Façade de face, enseigne lisible. |
| `salle/salle.jpg` | Bloc « Privatiser » | La salle vide ou en fin de service, chaleureuse. |
| `plats/bo-bun.jpg` | Carte, tuile Bo bun, bloc « Le midi », page SEO | Vu de dessus, sur la table en bois. |
| `plats/banh-mi.jpg` | Carte, tuile Banh mi | Coupé en deux pour voir la garniture. |
| `plats/sandwich.jpg` | Carte, tuile Sandwichs | Le sandwich du moment. |
| `plats/salade.jpg` | Carte | |
| `plats/plat-du-jour.jpg` | Carte, tuile Plats du moment | |
| `plats/tartiflette.jpg` | Carte, tuile Plats du moment | Dans son plat, fumante. |
| `apero/planche.jpg` | Carte, tuile Apéro | Avec deux verres. |
| `apero/verres.jpg` | Carte | |
| `apero/rhums-arranges.jpg` | Carte, tuile Rhums, bloc « L'apéro », page SEO | Les bocaux alignés derrière le bar, fruits visibles. |

Facultatif : une photo dédiée par tuile (`plats/tuile-sandwichs.jpg`, `tuile-bo-bun`, `tuile-banh-mi`, `tuile-moment`, `apero/tuile-apero.jpg`, `apero/tuile-rhums.jpg`), format portrait.

Les photos brutes (Google Maps, téléphone) peuvent être rangées dans `raw/` en attendant d'être triées.
